# @p9s/core

The configuration of [p9s](https://p9s.vercel.app), hierarchical permissions for Postgres enforced with Row Level
Security: its types, defaults and validation. Most projects use it through [`@p9s/postgres`](https://www.npmjs.com/package/@p9s/postgres)
or [`@p9s/cli`](https://www.npmjs.com/package/@p9s/cli).
