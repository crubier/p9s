# @p9s/drizzle

Derives the configuration of [p9s](https://p9s.vercel.app) from a [Drizzle](https://orm.drizzle.team) schema, so that the
tables and columns of the permission graph follow your schema. See the
[Next.js and Drizzle example](https://github.com/crubier/p9s/tree/main/examples/nextjs-drizzle).
