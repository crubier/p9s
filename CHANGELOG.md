# Changelog

The packages `@p9s/core`, `@p9s/postgres`, `@p9s/drizzle` and `@p9s/cli` share one version. The migration can be run
again on a database made by an earlier version: upgrading is generating it with the new version and running it, see
[upgrading](https://p9s.vercel.app/docs/configuration/upgrading).
